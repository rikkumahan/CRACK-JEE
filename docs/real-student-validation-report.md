# Real-World Knowledge Tracing Validation Report

_Completed 2026-09-15 by Antigravity on branch `antigravity/synthetic-jee-kt`. Evaluates zero-shot transfer of the pre-trained LKT model (trained on 35,000 synthetic JEE items) and BKT on an authentic JEE student's mock test attempts (223 questions across GTM08 -> GTM10 -> GTM06)._

---

## 1. Executive Summary & Protocol Alignment

Following completion of the synthetic benchmark (Phases 1–6), an authentic longitudinal dataset collected from a real student across three JEE Main Grand Test Mocks (GTM08, GTM10, GTM06) was provided to test real-world transferability:
- **Total Questions in Mocks:** 223 questions (Physics, Chemistry, Mathematics).
- **Attempted Questions:** 74 attempts (54 Correct, 20 Wrong, 73.0% actual accuracy).
- **Pre-trained LKT Model:** Trained exclusively on 35,000 synthetic interactions generated by our Rasch/2PL-IRT simulator.

### Methodological Findings & Verdict:
1. **Zero Concept Overlap (Not True Zero-Shot Transfer):**
   Exactly 0 of the 49 distinct concepts in the real student data (`Newtons_Laws`, `Fluid_Dynamics`, `Carnot_Cycle`, etc.) appear in the 1,029 eQOURSE concept IDs in the synthetic dataset (`Subject::Chapter::Topic`). As a result, LKT's learned concept-specific weights ($\beta_k$, $\gamma_k$, $\rho_k$) were completely inactive. LKT operated solely as a fallback on global features.
2. **Primary Metric (AUC per Protocol §2):**
   Neither model exhibits real discriminative ranking power on this concept-mismatched, 74-sample slice.
   - **LKT raw AUC is sub-chance:** **$0.4593$** (worse than the $0.50$ baseline of a random guess).
   - **BKT default AUC is marginally above chance:** **$0.5139$**.
3. **Thresholding Reality:**
   At its natural, un-tuned decision boundary ($0.50$), LKT achieves **$50.0\%$ accuracy**—substantially worse than predicting the student's base rate ($73.0\%$) and worse than the Recent-5 baseline ($70.3\%$). The previously noted $71.6\%$ figure was obtained by sweeping thresholds post-hoc on the test set ($0.45$) using known test labels, and is not a valid generalization metric.
4. **Flat Predicted Probability Spread:**
   LKT's predicted probabilities on Correct vs. Wrong items were nearly identical (**$0.524$** on Correct vs. **$0.516$** on Wrong, a difference of just $0.008$). Furthermore, across Easy, Medium, and Hard tiers, LKT's predicted probabilities varied by only 7.6 percentage points ($0.466$ to $0.542$), failing to track the student's actual 29.1 percentage point spread ($53.3\%$ to $82.4\%$).

## 2. Model Performance Comparison (Primary Metric: AUC)

Per `experimental-protocol.md §2`, AUC is the primary evaluation metric due to class imbalance (73% Correct vs. 27% Wrong):

| Model | Setup | AUC (Primary) | Accuracy (Natural 0.50) | Log Loss | RMSE | Brier Score |
|---|---|---|---|---|---|---|
| **BKT (Literature Default)** | Closed-form Bayes ($L_0=0.20, T=0.10, S=0.10, G=0.25$) | **$0.5139$** | $41.9\%$ | $0.7764$ | $0.5376$ | $0.2891$ |
| **Pre-trained LKT (Ours)** | Pre-trained on 35k synthetic items | **$0.4593$** | $50.0\%$ | $0.6851$ | $0.4955$ | $0.2455$ |
| **Recent-5 Baseline** | Rolling window | **$0.5088$** | $70.3\%$ | $1.9674$ | $0.5278$ | $0.2785$ |

> [!WARNING]
> While LKT achieves lower Brier Score ($0.2455$ vs. $0.2891$) and Log Loss ($0.6851$ vs. $0.7764$) due to generic logistic squashing near $0.50$, its discriminative ranking power (AUC $0.4593$) is below chance. Post-hoc threshold tuning (sweeping thresholds on test labels to pick $0.45 \to 71.6\%$) constitutes label leakage and cannot be reported as generalization accuracy.

- **Single Wrong followed by Single Correct ($[0, 1]$):**
  $P(L_0) = 0.200 \to P(L_1 \mid O=0) = 0.129 \to P(L_2 \mid O=1) = \mathbf{0.413}$

## 9. Architectural Decision for Production MCP Server

1. **No Evidence to Reopen `ex1.md §7.2`:**
   74 attempts from a single student on concept-mismatched data does not support replacing or augmenting BKT in production. LKT's sub-chance AUC ($0.4593$) and flat predicted probability spread confirm that supervised regression models cannot generalize to single-student out-of-vocabulary inputs.
2. **Production MCP Server Retains Fixed-Parameter BKT:**
   As originally specified in `ex1.md §7.2` and reaffirmed in `research-validation-report.md`, the production personal coach tool in `src/` must remain with fixed-parameter BKT.
3. **Research Track Boundary Maintained:**
   LKT's proven superiority on the 35,000-interaction population benchmark (AUC $0.6707$) demonstrates its value for multi-student cohort analytics, but it will not be deployed into the single-student MCP server.
