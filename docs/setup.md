# Setup & Commands

Fill these in with your project's ACTUAL commands. The pre-commit hook reads
the LINT_CMD / TEST_CMD marker lines below.

## Install
```
# e.g. npm install
```

## Lint  (read by pre-commit hook)
```
# LINT_CMD: e.g. npm run lint
```

## Test  (read by pre-commit hook)
```
# TEST_CMD: e.g. npm test
```

## Run locally
```
# e.g. npm run dev
```
